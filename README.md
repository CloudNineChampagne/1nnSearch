Privacy Policy – 1nnSearch

Privacy Policy for 1nnSearch
Last Updated: May 3, 2026

What 1nnSearch Does
1nnSearch is a Chrome extension that fills lodging search forms on Inntopia.com
based on the shorthand text you enter (for example, dates, number of guests, destination).
All processing happens locally inside your browser.

Information We Collect
No data is collected, stored, or transmitted anywhere.
The extension does not use analytics, tracking, or any third-party services.

How Your Data is Used
Any data you type into 1nnSearch is processed only in your browser
and is never sent to any server. The extension operates entirely offline.

Third-Party Services
This extension does not integrate with or send data to any third-party services.

Your Rights
Since no data is collected, there is no data to access, modify, or delete.
You can uninstall the extension at any time through Chrome's extension settings.

Limited Use Compliance
The use of information received from Google APIs will adhere to the
Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes to This Policy
If this policy changes, the updated version will be posted at this URL.
